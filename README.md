# เว็บรวม Datasheet สินค้า

ลูกค้าเลือก **ยี่ห้อ → โมเดล** แล้วเปิดดูหรือดาวน์โหลด Datasheet ได้เลย
เวลาอัปโหลดไฟล์เพิ่ม รายการบนเว็บจะอัปเดตเองภายใน 1–2 นาที โดยไม่ต้องแก้โค้ด

## วิธีวางไฟล์

ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ `datasheets/` โดยตั้งชื่อโฟลเดอร์เป็นยี่ห้อ และตั้งชื่อไฟล์เป็นรุ่น

```
datasheets/
├── SRNE/
│   ├── AEP4860S135-H.pdf          ← ชื่อไฟล์จะใช้เป็นชื่อรุ่น
│   └── HF4850S80-H.pdf
├── Growatt/
│   └── SPF 5000 ES.pdf
└── Deye/
    └── SUN-5K-SG04LP1/            ← ถ้ารุ่นนี้มีหลายไฟล์ ให้สร้างเป็นโฟลเดอร์
        ├── Datasheet.pdf
        └── คู่มือติดตั้ง.pdf
```

- ใช้ได้กับไฟล์ `.pdf` `.jpg` `.png` และ `.webp`
- ตั้งชื่อเป็นภาษาไทยหรือเว้นวรรคได้
- แต่ละไฟล์ต้องไม่เกิน 100 MB

## หน้าพนักงาน (แนะนำ) — `staff.html`

หน้านี้แยกจากหน้าลูกค้า พนักงานอัปโหลดไฟล์ได้เลยโดยไม่ต้องเข้า GitHub

- ลิงก์: `https://<ชื่อบัญชี>.github.io/datasheet/staff.html` — **ไม่ต้องใส่ลิงก์นี้ในเมนูร้าน**
- ถ้าไม่มีรหัสเข้าใช้ (Token) ลูกค้าที่เปิดเจอหน้านี้ก็แก้ไขอะไรไม่ได้
- หน้านี้ตั้งไว้ไม่ให้ Google เก็บไปแสดงผลค้นหา (noindex)

**วิธีใช้:** ใส่ยี่ห้อ → ใส่รุ่น → ลากไฟล์มาวาง (ใส่ได้หลายไฟล์ เช่น Datasheet และคู่มือ) → ตั้งชื่อเอกสาร → กด **อัปโหลดขึ้นเว็บ**
ด้านล่างของหน้ามีรายการรุ่นทั้งหมด กด **ลบ** หรือ **ลบทั้งรุ่น** ได้จากตรงนั้น

### สร้างรหัสเข้าใช้ให้พนักงาน (เจ้าของร้านทำครั้งเดียว)
1. ไปที่ GitHub → รูปโปรไฟล์ → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. **Repository access:** เลือก *Only select repositories* → เลือก repo `datasheet` เท่านั้น
3. **Permissions → Repository permissions → Contents:** เลือก **Read and write** (ไม่ต้องเปิดสิทธิ์อื่น)
4. ตั้งวันหมดอายุ (เช่น 1 ปี) → กด Generate แล้วคัดลอกรหัส `github_pat_...`
5. เปิด `staff.html` → ใส่ repo (`ชื่อบัญชี/datasheet`) และรหัส → กด **บันทึกและทดสอบ**
   เครื่องนั้นจะจำรหัสไว้ ครั้งต่อไปไม่ต้องใส่ใหม่

> ⚠️ รหัสนี้แก้ไขได้เฉพาะ repo datasheet เท่านั้น ถ้าพนักงานลาออก หรือสงสัยว่ารหัสหลุด ให้กด **Delete** รหัสนั้นใน GitHub แล้วสร้างรหัสใหม่ทันที

## ภาพโปรโมชั่นในหน้าลูกค้า

ภาพจะแสดงใต้ช่องค้นหา ขนาดแนะนำคือ 2 ภาพ ขนาดเท่ากัน (1200×628 หรือ 1080×1080) ไม่เกินไฟล์ละ 1 MB

**วิธีที่ 1: ผ่านหน้าพนักงาน (แนะนำ)**
1. เปิด `staff.html` ไปที่หัวข้อ **ภาพโปรโมชั่น (หน้าลูกค้า)**
2. **เพิ่มภาพ:** กด **＋ เพิ่มภาพโปรโมชั่น** แล้วเลือกไฟล์
3. **ชื่อโปร:** ใส่ชื่อ เช่น "โปรแผงโซล่า ธ.ค." ชื่อนี้ใช้ดูสถิติใน GA4
4. **ลิงก์:** ใส่ได้ ถ้าเว้นว่างจะไปหน้าโปรของร้าน
5. **จัดการภาพ:** ใช้ ↑ ↓ เปลี่ยนลำดับ และกด **ลบ** สำหรับโปรที่หมดแล้ว
6. กด **บันทึกโปรโมชั่น** แล้วหน้าลูกค้าจะเปลี่ยนใน 1–2 นาที

**วิธีที่ 2: ผ่าน GitHub โดยตรง**
- **เพิ่มภาพ:** เปิดโฟลเดอร์ `promos` → **Add file → Upload files** → ลากภาพมาวาง → **Commit changes**
- **ลบภาพ:** กดที่ไฟล์ → ⋯ → **Delete file**
- ภาพที่เพิ่มทางนี้จะลิงก์ไปหน้าโปรของร้าน และเรียงตามชื่อไฟล์ ถ้าอยากตั้งชื่อโปรหรือลิงก์เอง ให้ใช้หน้าพนักงาน

ลิงก์ตั้งต้นของภาพโปรอยู่ที่ `promoUrl` ใน `CONFIG` ของ `index.html`
GA4 จะเก็บ event `view_promotion` (เห็นภาพ) และ `select_promotion` (กดภาพ) พร้อมชื่อโปร

## ระบบเตือนรุ่นที่ยังไม่มี Datasheet

ทุก **วันจันทร์ 08:00** ระบบจะเทียบรายการรุ่นในชีต Models ของระบบรับประกันกับไฟล์ที่มีอยู่ แล้วอัปเดต Issue ชื่อ **"📋 รุ่นที่ยังไม่มี Datasheet"** ในแท็บ **Issues** ของ repo

- ระบบอ่านข้อมูลจากระบบรับประกันอย่างเดียว ไม่แก้ไขอะไร
- จะมี**อีเมลแจ้งเตือน**เมื่อ: สร้างรายการครั้งแรก, มีรุ่นใหม่เข้าระบบรับประกันแต่ยังไม่มีไฟล์ และสรุปทุกวันจันทร์แรกของเดือน
- อัปโหลดไฟล์ครบแล้ว รุ่นนั้นจะหายจากรายการเอง ถ้าครบทุกรุ่น ระบบจะปิด Issue ให้อัตโนมัติ
- ถ้าอยากเช็กตอนนี้เลย: แท็บ **Actions → Datasheet reminder → Run workflow**
- ถ้าไม่ได้รับอีเมล ให้ตรวจว่าเปิด **Watch** repo นี้ไว้ (เจ้าของ repo จะเปิดไว้ให้อัตโนมัติ) และดูในโฟลเดอร์ Junk/Spam ด้วย

> ถ้า repo ไม่มีความเคลื่อนไหวเลย 60 วัน GitHub จะหยุดงานตั้งเวลาอัตโนมัติ และส่งอีเมลเตือนก่อน แค่อัปโหลด Datasheet สักไฟล์ หรือกดปุ่มในอีเมลนั้น ก็จะกลับมาทำงานต่อ

## วิธีอัปโหลดผ่านหน้าเว็บ GitHub (ทางเลือก)

**เพิ่มรุ่นในยี่ห้อที่มีอยู่แล้ว**
1. เข้า repo แล้วเปิดโฟลเดอร์ `datasheets` → `SRNE` (หรือยี่ห้ออื่นที่ต้องการ)
2. กด **Add file → Upload files**
3. ลากไฟล์ PDF มาวาง แล้วกด **Commit changes**

**เพิ่มยี่ห้อใหม่**
1. ในคอมพิวเตอร์ ให้สร้างโฟลเดอร์ชื่อยี่ห้อ เช่น `Growatt` แล้วใส่ PDF ไว้ข้างใน
2. ใน GitHub เปิดโฟลเดอร์ `datasheets` แล้วกด **Add file → Upload files**
3. ลาก **ทั้งโฟลเดอร์** มาวาง แล้วกด **Commit changes**

**ลบหรือเปลี่ยนชื่อ:** กดที่ไฟล์ → ไอคอน ⋯ → Delete file หรือแก้ชื่อ (ดินสอ) แล้วกด Commit

หลังกด Commit ให้รอประมาณ 1–2 นาที แล้วรีเฟรชหน้าเว็บ ดูสถานะได้ที่แท็บ **Actions** (ขึ้นสีเขียวแปลว่าอัปเดตเสร็จแล้ว)

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. สร้าง repo ใหม่บน GitHub แบบ **Public** เช่นชื่อ `datasheet`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป รวมถึงโฟลเดอร์ `.github`
3. ไปที่ **Settings → Pages** แล้วตั้ง **Source** เป็น **GitHub Actions**
4. ไปที่แท็บ **Actions** แล้วเลือก **Build & deploy site** → **Run workflow**
5. เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/datasheet/`

### ใส่ชื่อร้านและปุ่ม LINE
แก้ไฟล์ `index.html` ตรงส่วน `CONFIG` ด้านล่างของไฟล์:

```js
const CONFIG = {
  siteName: "SolarCellDIY · Datasheet",
  lineUrl: "https://lin.ee/xxxxxxx"
};
```

## ส่งลิงก์ให้ลูกค้า
เปิดรุ่นที่ต้องการบนเว็บ แล้วกด **คัดลอกลิงก์รุ่นนี้** จะได้ลิงก์ที่เปิดตรงไปยังรุ่นนั้น ส่งทาง LINE ได้เลย
